# Testing

Drafts live here until a command is trusted.

**What goes here:**

- Output from any command that's new or was just changed.
- Recreations of past months made while building a command (`commands/setup/new-command.md`),
  named with " - TEST" at the end.

**When a command graduates:** after its output has been reviewed against a known-good result
and approved by someone other than the person who ran it. We suggest two clean months. Then
change the command's "Save to" line from `testing/` to the real close folder, and add a line to
the Changelog in `CLAUDE.md`.

**Housekeeping:** clear out old test files once a command graduates, so this folder only holds
what's currently being tested.
