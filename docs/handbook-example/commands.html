Commands

Recurring tasks Claude runs the same way every month. Run them from the finance folder.

Setup

Command What it does
commands/setup/build-handbook.md Build or refresh the finance handbook. Drafts every handbook page from your docs and connected systems, then interviews you only on what they can't answer.
commands/setup/follow-up-interview.md A 30-minute follow-up with whoever owns the numbers. Fills the metrics, plan, reporting, and people sections the books can't answer.
commands/setup/new-command.md Turn one recurring task you know cold into a reusable command. Recreates last month's version, compares it to the real one until it matches, then writes the command.

Journal entries

Command What it does
commands/jes/prepaid-amortization.md Prepare the monthly prepaid amortization JE from the prepaid schedule, add new prepaids from the month's bills, and tie the schedule to the GL.
commands/jes/usage-accrual.md Prepare the month-end accrual for usage-billed vendors (cloud, APIs, data) whose invoice hasn't arrived yet, as a reversing JE.

Reconciliations

Command What it does
commands/recs/bank-reconciliation.md Reconcile a bank or card account's GL balance to its statement, classify every reconciling item, roll forward last month's items, and propose entries for anything unrecorded.

Publishing

Command What it does
commands/publish/build-handbook-site.md Publish the handbook as a browsable internal website (static HTML, no tools to install), so people who never open this folder can still read the policies.
Built from the handbook/ folder on 2026-10-28. Edit the markdown, then rebuild with commands/publish/build-handbook-site.md.
