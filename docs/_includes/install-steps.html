Install

You'll need Claude Cowork (the Cowork tab in the Claude desktop app, on a Pro, Max, Team, or Enterprise plan). Everything installs from inside Cowork — no command line.

  1. Add the airCFO marketplace (once — skip this if you've installed any airCFO tool before): click Customize in the left sidebar, then Browse plugins → Personal → + → Add marketplace from GitHub, and enter {{ site.marketplace_url }}
  2. Install {%- for plugin_name in include.plugins %} {{ plugin_name }}{% unless forloop.last %}, then{% endunless %}{% endfor -%} . Already installed? Click Update on the marketplace instead, so you have the latest version.
    3. {%- if include.direct_systems.size > 0 %}
  3. Connect {{ include.direct_systems | join: " and " }} in Claude's connector settings, read-only, with your own login, using the vendor's own connector (Intuit's, for QuickBooks). Not connected? The tool asks for the export it needs instead.
    4. {%- endif %} {%- if include.needs_finance_brain %}
  4. Work from your Finance Brain if you have one: open the folder with Work in a folder so the tool reads your definitions. No Finance Brain yet? Download the free starter kit.
    5. {%- endif %} {%- if include.ask %}
  5. Ask: {{ include.ask }}
    6. {%- endif %}

Missing one of the systems above? The tool still runs. Whatever it couldn't read shows up as an open question, never a guess.
